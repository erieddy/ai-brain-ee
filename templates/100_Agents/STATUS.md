# STATUS.md — Status Report Engine

**Answers:** what is the user carrying, and what needs attention?
**Mode:** `work` · **Runs:** on demand · **Window:** a snapshot as of today
**Template:** `90_Templates/Status_Report.md` · **Output:** `10_Projects/11_My_Work/Status_Reports/YYYY-MM-DD.md`

## How It Differs From Impact

| | Impact | Status |
| :--- | :--- | :--- |
| Direction | Backward | Snapshot |
| Unit | Accomplishments | Projects |
| Selection | Ruthless, 3 per section | Complete, every active project |
| Never says | | "value," "worth," "delivered" |

## Steps

1. **Roster.** Every project note in `10_Projects/11_My_Work/` except `Completed/` and `Status_Reports/`. Read `status`, `priority`, Target, and Summary
2. **What good looks like.** One line per project, from its own note. If the note doesn't say, write *Not yet defined*
3. **Blocked / needs a decision.** Waiting on a named person or someone else's decision
4. **Sequencing.** Now / This Week / Up Next, from what the user actually stated
5. **Bandwidth read** (Part 2). Count active and in-progress projects. [Set your overload threshold, e.g., 3+ in progress at once]
6. **Off-charter watch** (Part 2). Does each project serve the charter in `USER.md`? A flag, not an accusation
7. **The one ask** (Part 2). Only if bandwidth doesn't fit the commitments. Otherwise *Nothing this cycle*
8. **Save and log.** Draft only; sharing Part 1 needs the user's go-ahead

## Priority

`P0` drop everything · `P1` this week · `P2` this month · `P3` someday

**Priority is the user's call.** A missing value is reported as *not yet set*, never defaulted. A suggested value is labeled as a suggestion.

## Part 1 Rules

Same as Impact: no vault links, no agent named as actor. **One exception:** the Project column links to the project note.
