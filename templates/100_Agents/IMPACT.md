# IMPACT.md — Weekly Impact Report Engine

**Answers:** what did the user deliver this week, and what was it worth?
**Mode:** `work` · **Runs:** Fridays · **Window:** Monday 00:00 to Friday 23:59
**Template:** `90_Templates/Impact_Report.md` · **Output:** `20_Areas/21_My_Work/Weekly_Summaries/YYYY-MM-DD.md` (the Monday)

## Three Reports, Never Mixed

| Report | Question |
| :--- | :--- |
| **Impact** | What was delivered, and what was it worth? (backward) |
| **Status** | What is on the plate right now? (snapshot) |
| **Life** | What's happening outside work? (personal) |

If the user asks for "an update," check which one they mean.

## The Value Test

**Every bullet names a business consequence:** revenue or pipeline, time or cost saved, risk avoided, capability created, or a decision changed. **No consequence means it's activity, and it's cut.**

**Max 3 items per section.** A ceiling, not a target. Choosing the 3 that matter is the work.

## Steps

### 0. Preflight (hard stop)

- [ ] The Inbox is swept for the week
- [ ] Session logs exist for the week

If not, run the sweep first and say so.

### 1. Gather

- **Project notes** (primary): `status: done` with a `completed:` date in the window; Current State changes
- **Meeting notes** in the window: outcomes and decisions
- **Session logs** and **people notes**: supporting evidence

### 2. Classify

Each item gets **exactly one** section. Work down the list; the first test it passes wins.

1. **Reality checks:** did a claim, plan, or scope change because the user tested it?
2. **Enablement:** is someone else now more capable?
3. **Cross-functional:** did the user move something that isn't theirs? Name the counterpart
4. **Wins & assets:** does something finished exist that didn't before?
5. **Next week's focus:** from projects in `backlog`, `in-progress`, or `blocked`

**Never include:** attendance with no outcome, reading with no artifact, unfinished work, plans restated as accomplishments.

### 3. Write

- **Bullet formula:** `[consequence] because [the user did X]`. Lead with the consequence
- **Quantify only real numbers.** "8 people can now run the demo" is impact; "8 meetings attended" is a timesheet
- **Headline last:** one line, the week's biggest consequence. A thin week gets an honest headline
- **Empty section:** `*Nothing this week.*`

### 4. Part 1 rules (shareable)

- No links to projects, meetings, or vault files. Plain prose, ready to paste
- People links are fine
- **No agent is ever named as the actor.** The team's work is the user's work

### 5. Part 2 (the user only)

Patterns (2+ sources), Slipping & Stalled (open 3+ days), Relationship Watch (top-tier contacts with `last_contact` over 30 days), Where the Week Went (time vs stated priorities), The One Thing. **A Part 2 that reads as reassuring has failed.**

### 6. Save and log

Save from the template, log in `101_long_term_memory/`, update `MEMORY.md` only for lasting changes.

## Self-Check

Could the user's manager read Part 1 in 90 seconds and repeat the user's value an hour later without opening the vault?
